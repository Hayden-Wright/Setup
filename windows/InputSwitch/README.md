# InputSwitch

Убирает всплывающее окно переключения раскладки.

[![Скачать](https://img.shields.io/badge/Скачать-InputSwitch.zip-blue?style=for-the-badge&logo=github)](https://github.com/Hayden-Wright/setup/raw/main/windows/InputSwitch/InputSwitch.zip)

Распаковать, запустить от администратора:

- `KILLTHISDIALOG.bat` — выключить
- `RETURNTHISDIALOGBOX.bat` — вернуть обратно

DLL берётся из папки с батником, поэтому запускать из распакованной папки.
Explorer перезапустится, экран моргнёт.
