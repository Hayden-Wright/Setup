# InputSwitch

**Скачать всё одним файлом:** [`InputSwitch.zip`](./InputSwitch.zip)

Архив содержит файлы для отключения и восстановления всплывающего окна переключения раскладки.

## Использование

1. Скачайте и распакуйте `InputSwitch.zip` в отдельную папку.
2. Запустите нужный `.bat` **от имени администратора**.
3. Не перемещайте `.bat` отдельно от DLL-файлов: скрипты берут DLL из своей папки.

- `KILLTHISDIALOG.bat` — отключить окно.
- `RETURNTHISDIALOGBOX.bat` — вернуть исходное поведение.

При выполнении перезапускается Проводник Windows, поэтому экран может кратковременно мигнуть.

> Запускайте только если доверяете содержимому архива. Скрипты меняют системный DLL-файл и его разрешения.
