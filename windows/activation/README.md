# Активация Windows

Активация Windows 11 через KMS. Три сценария: **Pro**, **Pro (резервный ключ)**
и **Home**.

> **Важно.** Активация идёт через сторонний публичный KMS-сервер
> (`kms.digiboy.ir`), то есть в обход официального лицензирования. Ключи ниже —
> это GVLK (generic volume license keys), они опубликованы Microsoft и секретом
> не являются. Машина на время активации обращается к чужому серверу — держи
> это в голове.

## Перед началом

Узнай свою редакцию Windows — от неё зависит, какой ключ вводить:

```powershell
Get-ComputerInfo | Select-Object WindowsProductName, WindowsEditionId
```

Или короче:

```cmd
slmgr /dli
```

| Редакция | Раздел |
| --- | --- |
| Windows 11 Pro | [Pro](#windows-11-pro) |
| Windows 11 Home | [Home](#windows-11-home) |

## Как выполнять

1. Открой **Терминал от имени администратора** (ПКМ по «Терминал» → «Запуск от имени администратора»).
2. Выполняй команды **по одной**, в том порядке, что в разделе.
3. После `/ato` подожди 10–30 секунд — активация идёт не мгновенно.

Если запускаешь через PowerShell и ругается на `slmgr`, используй `slmgr.vbs`:

```powershell
slmgr.vbs /ipk <КЛЮЧ>
```

## Windows 11 Pro

### Вариант 1 (основной)

Ввод ключа:

```cmd
slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
```

Указание KMS-сервера:

```cmd
slmgr /skms kms.digiboy.ir
```

Запуск активации:

```cmd
slmgr /ato
```

### Вариант 2 (если первый не сработал)

Первый ключ может не подойти, если он уже выжжен в прошивке или система
ругается на несовпадение редакции. Тогда тот же порядок, но с другим ключом:

```cmd
slmgr /ipk 8N67H-M3CY9-QT7C4-2TR7M-TXYCV
```

```cmd
slmgr /skms kms.digiboy.ir
```

```cmd
slmgr /ato
```

## Проверка результата

```cmd
slmgr /xpr
```

Должно ответить, что Windows активирована постоянно (или до даты — это нормально
для KMS, продление идёт автоматически, пока машина видит KMS-сервер).

Подробный статус лицензии:

```cmd
slmgr /dlv
```

## Если не сработало

**`Ошибка: 0xC004F074`** — не удалось связаться с KMS-сервером.
Проверь интернет и попробуй другой KMS-сервер (адрес в команде `/skms` можно
заменить). Частая причина — блокировка порта 1688 провайдером или файрволом.

**`Ошибка: 0xC004F069`** — введён ключ не от той редакции. Уточни редакцию
командой `slmgr /dli` и возьми ключ из нужного раздела.

**`Ошибка: 0x8007232B`** — ключ не был принят вообще. Проверь, что терминал
действительно запущен от администратора.

**Ключ не принимается на Pro, но принимается на Home (или наоборот)** — значит,
редакция определена неверно. Смотри таблицу выше.

## Смена ключа / сброс

Посмотреть текущий ключ (последние 5 символов):

```cmd
slmgr /dli
```

Снять текущий ключ и ввести новый:

```cmd
slmgr /upk
slmgr /ipk <НОВЫЙ_КЛЮЧ>
slmgr /skms kms.digiboy.ir
slmgr /ato
```

Перечитать лицензионную информацию с диска:

```cmd
slmgr /ril
```
