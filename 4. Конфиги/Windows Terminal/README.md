# Windows Terminal

Тема Catppuccin Mocha, шрифт JetBrainsMono Nerd Font, прозрачность 80%.

![](screenshot.png)

## Как поставить

[![Скачать шрифт](https://img.shields.io/badge/Скачать-JetBrainsMono.zip-blue?style=for-the-badge&logo=github)](https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.zip)

1. Поставить JetBrainsMono Nerd Font (кнопка выше) — распаковать и установить `.ttf`
2. В терминале `Ctrl+Shift+,` → «Открыть файл JSON».
3. Заменить содержимое на [settings.json](settings.json), сохранить.
