# setup

Личный архив настроек: конфиги, команды, инструкции по программам и системе.
Всё, что я настраивал под себя и не хочу настраивать заново.

Это не проект и не библиотека — просто склад. Ценность в том, что всё лежит в
одном месте, версионируется и переживает переустановку системы.

## Разделы

| Раздел | Что внутри |
| --- | --- |
| [windows](windows/) | Настройка Windows 11: активация, твики, реестр |

## Как устроено

```
setup/
├── README.md          # этот файл: оглавление
├── .gitignore
└── windows/           # раздел = тема
    ├── README.md      # оглавление раздела
    └── activation/    # подтема = папка с README
        └── README.md
```

Правила, чтобы не превратилось в свалку:

- **Одна тема — одна папка**, в ней `README.md` с пошаговой инструкцией.
  Глубина: `раздел/подтема/README.md`. Не глубже.
- **Никаких `.bat` и `.exe`.** Только команды в блоках кода и текстовые конфиги:
  их видно, можно скопировать по одной и понимать, что происходит.
- **Файлы конфигов — как есть**, с указанием пути, куда их класть.
- **Никаких секретов.** Токены, API-ключи, пароли, ssh-ключи и личные пути —
  не сюда. Нужен ключ для приложения — в репозитории шаблон с `<ПЛЕЙСХОЛДЕРОМ>`.
- **Один пункт — один коммит.** Чтобы история читалась и можно было откатить
  конкретную настройку.

## Заметки

- Репозиторий **приватный** и таким должен остаться: часть содержимого —
  обход лицензирования Windows.
- Команды для Windows выполняются в **терминале от администратора**, если в
  инструкции не сказано иное.
