# Windows 11 Setup

Личная шпаргалка по настройке Windows 11: активация, твики, конфиги приложений.
Всё хранится в виде команд и файлов, которые можно скопировать и применить вручную.

## Как пользоваться

1. Открой терминал **от имени администратора** (ПКМ по «Терминал» → «Запуск от имени администратора»).
2. Зайди в нужную папку репозитория.
3. Копируй команды из `README.md` этой папки по одной и выполняй.
4. Где нужно заменить файл конфига — в инструкции указан путь назначения.

## Структура репозитория

```
windows-setup/
├── README.md          # этот файл: оглавление и правила
└── activation/        # один раздел = одна папка = один README
    └── README.md
```

Правила, чтобы не превратилось в свалку:

- **Одна тема — одна папка.** Внутри папки `README.md` с пошаговой инструкцией.
- **Никаких `.bat`.** Только команды в блоках кода: их видно, их можно скопировать
  по одной и понимать, что происходит.
- **Никаких секретов.** Токены, API-ключи, пароли и личные пути — не сюда.
  Если ключ нужен для работы приложения, в репозитории лежит шаблон с
  плейсхолдером вида `<ТВОЙ_API_КЛЮЧ>`.

## Заметки

- Репозиторий **приватный**. Публичным делать не стоит: часть содержимого —
  обход лицензирования Windows.
