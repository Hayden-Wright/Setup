Zim-стек с нуля

Терминальный Claude Code через локальный прокси и браузерный чат с доступом к машине — на чистой WSL Ubuntu. Все ключи и адреса те же, что у Хейдена.

WSL2 · Ubuntu · zsh ~20 минут 5 шагов архив 41 КБ
Сначала про ключ

Ключ Token Juice (tj_…) лежит открытым текстом в файле config/token публичного репозитория Mr-Destroyer/zim-claude — он отдаётся наружу по прямой ссылке, это проверено запросом. Ключ будет прописан на обеих машинах и оплачивается с одного счёта: расход и лимиты общие. Смени его в Token Juice и подставь новый в ~/claude-source/deepseek-claude на обеих машинах — иначе лимит может закончиться не у тебя.

Что получится

Две независимые половины. Их можно ставить по отдельности: если браузерная часть не нужна — скрипт можно остановить и пропустить её.

Установка

Один скрипт ставит всё: пакеты, Docker, Claude Code, zim-claude, твои доработки, SearxNG, cptr и Open WebUI. Он же создаёт ключи — токен Token Juice берётся из репозитория zim-claude, а ключ доступа Open WebUI к агенту генерируется свой.

01

Разрешить WSL и systemd Windows

В Windows PowerShell от администратора. Если WSL уже стоит — пропусти. 

wsl --install -d Ubuntu

Внутри Ubuntu включи systemd — без него не поднимется Docker:

sudo tee /etc/wsl.conf >/dev/null <<'EOF'
[boot]
systemd=true
EOF

Потом в Windows выполни wsl --shutdown и зайди в Ubuntu заново.

02

Забрать файлы WSL

Все файлы установки лежат в одном архиве. Скачай его и распакуй — дальше всё делает скрипт внутри. 

cd ~
tar xzf zim-claude-friend.tar.gz
cd zim-claude-friend

Архив передай любым способом: через мессенджер, облако или флешку. Размер 41 КБ.

03

Запустить установку WSL

Одна команда. Скрипт сам поймёт, что уже установлено, и спросит пароль от системы только когда понадобится ставить пакеты. 

./install-friend.sh
Скрипт можно запускать сколько угодно раз

Он ничего не ломает повторным запуском: уже сделанное пропускает. Если чего-то не хватает — скажет, чего именно, и попросит запустить себя снова.

Первый запуск может прерваться дважды, и это нормально: после установки Docker нужно закрыть и заново открыть терминал, чтобы применились права. Скрипт прямо об этом скажет.

04

Зарегистрироваться в cptr браузер

Единственный шаг, который нельзя автоматизировать. Скрипт сам напечатает ссылку с одноразовым токеном — открой её и придумай логин с паролем.

Логин и пароль локальные: это вход в программу на своём компьютере, никуда они не отправляются. После регистрации запусти ./install-friend.sh ещё раз — скрипт доделает остальное: настроит агента и поднимет Open WebUI.

05

Готово WSL

Проверить, что всё живо:

zim-claude

Внутри спроси что-нибудь простое. Если ответил — работает. Дальше:

zim-claudeтерминальный Claude Code
127.0.0.1:3000чат в браузере
zim-memory search "…"поиск по заметкам и истории
~/start-all.shподнять всё сразу после перезагрузки

Порт 3000 исключение: контейнер запущен с --network host, поэтому если WSL пробрасывает порты на Windows, чат виден любому в локальной сети. Закрыть можно, но тогда Open WebUI не достучится до SearxNG и cptr по 127.0.0.1 — понадобятся другие адреса, так что просто поменять флаг нельзя.

Что может сломаться

  • Обновление cptr затирает патчи. После pip install -U cptr повтори команды patch из установщика. Версия 0.9.21 зафиксирована именно поэтому.
  • Веб-поиск молча деградирует до коротких сниппетов, если в контейнере Open WebUI нет ENABLE_LOCAL_WEB_FETCH. Поэтому контейнер поднимается только через run-openwebui.sh, а не руками.
  • Чаты без названий и без follow-up кнопок. Известная нерешённая проблема: cptr отвечает 503 на служебные задачи вроде генерации заголовка. Основной чат при этом работает.
  • Имя модели обманчиво. claude-opus-5-5 — это псевдоним DeepSeek. Claude Desktop показывает его как модель уровня Opus только потому, что иначе отказывается показывать не-Anthropic модели.
  • Окно контекста 262144, а не миллион. Столько режет апстрим; значение прописано и в env-профиле CLI, и в конфиге cptr. Менять его на большее смысла нет — запрос упадёт на стороне апстрима.
