Zim-стек с нуля

Терминальный Claude Code и Claude Desktop через локальный прокси — на чистой WSL Ubuntu. Надстройка над zim-claude: ставит то, чего в нём нет.

WSL2 · Ubuntu · bash ~20 минут 5 шагов один скрипт
Сначала про ключ

Ключа в репозитории нет и не будет. Ключ Token Juice (tj_…) спросит установщик zim-claude — ввод скрыт, в историю команд он не попадает. Свой ключ берётся в личном кабинете Token Juice: расход и лимиты у каждого свои, чужие ключи не используются.

Для неинтерактивной установки ключ можно передать переменной: ZIM_CLAUDE_TOKEN=tj_… ./install-stack.sh.

Что получится

Одна трасса: обе программы говорят с локальным LiteLLM, тот переводит запросы в DeepSeek. Браузерного чата (Open WebUI + cptr) больше нет — его заменяет Claude Desktop, подключённый к шлюзу на :4002.

Установка

Один скрипт ставит всё: пакеты, Docker, Claude Code, zim-claude, доработки и SearxNG (движок для веб-поиска в обоих приложениях). Ключ Token Juice он спросит. Claude Desktop ставится с сайта Anthropic и подключается к шлюзу http://127.0.0.1:4002 один раз.

01

Разрешить WSL и systemd Windows

В Windows PowerShell от администратора. Если WSL уже стоит — пропусти. 

wsl --install -d Ubuntu

Внутри Ubuntu включи systemd — без него не поднимется Docker:

sudo tee /etc/wsl.conf >/dev/null <<'EOF'
[boot]
systemd=true
EOF

Потом в Windows выполни wsl --shutdown и зайди в Ubuntu заново.

02

Забрать файлы WSL

Одна команда скачивает папку с файлами установки из репозитория. 

cd ~
curl -fsSL https://github.com/Hayden-Wright/Setup/archive/refs/heads/main.tar.gz \
  | tar xz --strip-components=2 --one-top-level=zim-setup Setup-main/Claude-Code
cd zim-setup

Скачивается только эта папка, остальной репозиторий не тянется.

03

Запустить установку WSL

Одна команда. Скрипт сам поймёт, что уже установлено, и спросит пароль от системы только когда понадобится ставить пакеты. 

./install-stack.sh
Скрипт можно запускать сколько угодно раз

Он ничего не ломает повторным запуском: уже сделанное пропускает. Если чего-то не хватает — скажет, чего именно, и попросит запустить себя снова.

Первый запуск может прерваться дважды, и это нормально: после установки Docker нужно закрыть и заново открыть терминал, чтобы применились права. Скрипт прямо об этом скажет.

04

Готово WSL

Проверить, что всё живо:

zim-claude

Внутри спроси что-нибудь простое. Если ответил — работает. Дальше:

zim-claudeтерминальный Claude Code
Claude DesktopGateway → http://127.0.0.1:4002, ключ sk-claude-desktop-local
zim-memory search "…"поиск по заметкам и истории
~/start-all.shподнять всё сразу после перезагрузки

Оба прокси слушают на всех интерфейсах, чтобы до них доставалось приложение на Windows. Ключ у шлюза :4002 статический, так что порт стоит держать закрытым извне — это внутренняя машина.

Что может сломаться

  • Веб-поиск отвечает ошибкой. Не поднят SearxNG: docker start searxng либо ~/start-all.sh.
  • Имя модели обманчиво. claude-opus-5-5 — это псевдоним DeepSeek. Claude Desktop показывает его как модель уровня Opus только потому, что иначе отказывается показывать не-Anthropic модели.
  • Окно контекста у Token Juice 262144, а не миллион. Столько режет апстрим. В Claude Desktop и в CLI окно берётся из GET /v1/models, отдельно его прописывать не нужно. Менять его на большее смысла нет — запрос упадёт на стороне апстрима.
