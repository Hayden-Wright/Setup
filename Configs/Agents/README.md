# MCP / Skills etc

Что настроено у агента: серверы, скиллы и правила.

## MCP

| Сервер | Что даёт | URL |
|---|---|---|
| `deploychan` | каталог знаний, скиллов и маршрутов | `https://mcp.deploychan.webcam/mcp` |
| `context7` | документация библиотек | `https://mcp.context7.com/mcp` |

Оба — remote, streamable HTTP, без авторизации. Инструменты агент вызывает сам,
заранее ничего читать не нужно.

## Skills

Встроенные, отдельных файлов нет: `browser`, `opencode`, `report`.

| Файл | Что внутри |
