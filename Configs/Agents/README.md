# MCP / Skills etc

Что стоит у агента: MCP-серверы и правила, по которым он работает.

| Сервер | Что даёт |
|---|---|
| [deploychan](https://mcp.deploychan.webcam) | каталог знаний, готовых скиллов и маршрутов прокачки |
| [context7](https://context7.com) | актуальная документация библиотек и API |

Оба — remote, streamable HTTP, без авторизации. Инструменты агент вызывает сам,
когда они понадобились.

## deploychan

<img src="deploy-tan.png" width="160" align="right" alt="деплой-тян — маскот deploychan">

Публичный каталог опыта в вайбкодинге от KISA: курированные знания, готовые
скиллы, маршруты прокачки. Бесплатно, без логина, без ключей.

Установщик не нужен. Установка — одна ссылка, которую агент читает сам:
открой [mcp.deploychan.webcam](https://mcp.deploychan.webcam) в агентной сессии
и скажи «подключи».

Голая строка, одна на всех клиентов:

```
https://mcp.deploychan.webcam/mcp
```

### Инструменты

| Инструмент | Зачем |
|---|---|
| `list_recommended` | с чего начать, если непонятно чего хочется |
| `onboard` | маршрут под конкретную цель: шаги по порядку |
| `next_step` | материалы и действие одного шага маршрута |
| `search_knowledge` | поиск по заметкам, гайдам и скиллам |
| `get_item` | полный текст любой записи каталога |
| `list_skills` | список готовых скиллов |
| `get_skill` | устройство скилла и порядок установки |

### Что стоит знать

- **Каталог только на чтение.** Сервер отдаёт текст, установку выполняет агент —
  по вашим правилам и с вашими правами.
- **Рекомендация ≠ разрешение.** Установка скиллов, хуков и настроек — отдельный
  шаг, а не побочный эффект чтения.
- **Это не плагин.** Ничего не грузится в контекст постоянно — висят только
  описания семи инструментов.

### Проверить

```bash
curl -sS -X POST https://mcp.deploychan.webcam/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
```

В ответе должны быть те же семь инструментов из таблицы выше.

Убрать — `claude mcp remove deploychan`, в остальных клиентах удалить блок из
конфига.

## context7

Документация библиотек и фреймворков по запросу: агент спрашивает про
конкретную библиотеку, а не пересказывает память модели.

```
https://mcp.context7.com/mcp
```

| Инструмент | Зачем |
|---|---|
| `resolve-library-id` | найти библиотеку и получить её id |
| `query-docs` | задать вопрос по докам этой библиотеки |

`libraryId` — вида `/mongodb/docs`, с версией — `/vercel/next.js/v16.2.9`.

## AGENTS.md

Глобальные правила для агента — пять разделов, которые он держит в голове
постоянно: как говорить, когда искать, что делать с неуверенностью и как
оформлять ответ. Файл — [`AGENTS.md`](AGENTS.md).

| | Раздел | Что внутри |
|---|---|---|
| 💬 | **Терминология** | устоявшиеся термины, API и флаги — как в оригинале, без аналогий и жаргона |
| 🔎 | **Поиск** | только при неясной сигнатуре API, незнакомой ошибке, вопросе про версии и цены, по прямой просьбе |
| ⚖️ | **Честность** | не выдумывать ссылки и версии, помечать предположения, явно указывать противоречия |
| 🛠 | **Работа** | состояние проекта — по файлам; простые правки сразу; вопрос один и только при необратимости |
| 📝 | **Формат ответа** | коротко и структурировано, в конце этапа — строка «СЛЕДУЮЩИЙ ШАГ» |
