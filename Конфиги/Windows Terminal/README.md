# Windows Terminal

Тема Catppuccin Mocha, шрифт JetBrainsMono Nerd Font, прозрачность 80%.

## Как поставить

1. Поставить шрифт [JetBrainsMono Nerd Font](https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.zip) — без него поедут иконки.
2. Открыть настройки: в терминале `Ctrl+Shift+,` → «Открыть файл JSON».
3. Заменить содержимое на [settings.json](settings.json) из этой папки.
4. Сохранить — терминал подхватит сразу.

Старый файл лучше сохранить копией: он лежит в
`%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json`
